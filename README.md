# Учебный frontend-проект

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина техники и аксессуаров для учёбы.

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка». В сайте есть главная страница, каталог, карточка товара, страница заявки и контакты. Все страницы используют общую навигацию, единый CSS-файл, семантическую разметку и базовые БЭМ-классы.

## Структура проекта

- `index.html` — главная страница с hero-блоком, преимуществами и популярными товарами;
- `catalog.html` — каталог товаров, категории и статический блок фильтров;
- `product.html` — карточка товара, описание, цена и таблица характеристик;
- `product-notetab.html`, `product-focussound.html`, `product-codekeys.html` — отдельные страницы планшета, наушников и клавиатуры;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация и ссылка на форму заявки;
- `css/style.css` — общий файл стилей;
- `js/main.js` — минимальная логика модального окна и валидации формы;
- `images/` — изображения товаров и hero-блока;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Обязательные страницы

- Главная страница: hero-блок, преимущества, популярные товары и якорные ссылки.
- Каталог: сетка карточек товаров, категории и статический фильтр.
- Карточка товара: изображение, описание, цена, кнопка заявки и таблица характеристик.
- Заявка: форма с именем, e-mail, телефоном, выбранным товаром, комментарием и согласием.
- Контакты: контактная информация и переход к форме заявки.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- Flexbox для шапки, навигации и групп кнопок;
- CSS Grid для hero-блока, каталога, карточек и формы;
- базовое позиционирование: `sticky`, `relative`, `absolute`, `fixed`, `z-index`;
- структурированный файл `css/style.css`.

## Инструкция по просмотру

1. Открыть опубликованную версию через GitHub Pages.
2. Или открыть файл `index.html` в браузере локально.
3. Проверить переходы по меню: главная, каталог, товар, заявка, контакты.
4. Проверить форму заявки и модальное окно на главной странице.

Фильтры каталога статические, как предусмотрено заданием КР №1. Формы демонстрационные: проверяют поля и показывают результат, но не отправляют данные на сервер. Характеристики и контакты приведены для учебного примера.

## Использование Flexbox и Grid

- Flexbox для основного меню: `display: flex`, `flex-wrap`, `justify-content`, `align-items`, `gap`.
- Flexbox для внутренней структуры карточек товаров; действия прижаты к нижней части карточки.
- CSS Grid для `.products-grid`: три равные колонки и `gap`.
- CSS Grid для `.catalog-layout`: колонка фильтров 260px, колонка товаров и именованные области `filters products`.
- `.catalog-filters` использует `grid-area: filters`, `.catalog-products` — `grid-area: products`.
- Форма `.filters-form` содержит группы `fieldset`/`legend`, категории, поля цены и кнопку «Применить». Фильтры статические согласно заданию.

Ветка практики №6: `feature/flex-grid-navigation`.

## Практическая работа №7

Ветка: `refactor/bem-css-classes`. Аудит выявил смешение `form-field`/`form-actions` с элементами `order-form`, селекторы тегов внутри хлебных крошек, фильтров и таблиц, а также зависимость кнопок и бейджей от родительского блока.

После рефакторинга используются прямые классы: `order-form__field`, `order-form__actions`, `order-form__hint`, `breadcrumbs__link`, `breadcrumbs__current`, `filters-form__group`, `filters-form__legend`, `filters-form__label`, `filters-form__input`, `spec-table__cell`. Заголовки таблиц и бейджи имеют модификаторы вместе с базовым классом.

Основные блоки: `site-header`, `site-nav`, `breadcrumbs`, `hero`, `section`, `products-grid`, `product-card`, `catalog-layout`, `catalog-filters`, `filters-form`, `product-detail`, `spec-table`, `order-form`, `order-dialog`, `success-message`, `site-footer`. Карточка независима от страницы. Кнопка совмещает блок `button` и элемент `product-card__button` (микс).

CSS не использует ID и inline-стили. ID сохранены для якорей, подписей полей и JavaScript. Обработчик модального окна выбирает только кнопки с `data-product`, поэтому ссылки на страницу заявки не запускают его. Рефакторинг сохраняет оформление и сценарий заявки.
