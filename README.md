# Учебный frontend-проект

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина техники и аксессуаров для учёбы.

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка». В сайте есть главная страница, каталог, карточка товара, страница заявки и контакты. Все страницы используют общую навигацию, единый CSS-файл, семантическую разметку и базовые БЭМ-классы.

## Структура проекта

- `index.html` — главная страница с hero-блоком, преимуществами и популярными товарами;
- `catalog.html` — каталог товаров, категории и статический блок фильтров;
- `product.html` — карточка товара, описание, цена и таблица характеристик;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация и ссылка на форму заявки;
- `css/style.css` — общий файл стилей;
- `js/main.js` — минимальная логика модального окна и валидации формы;
- `images/` — изображения товаров и hero-блока;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;
- CSS Grid;
- Flexbox;
- БЭМ-именование классов;
- JavaScript для минимального открытия модального окна;
- Git;
- GitHub Pages.

## Обязательные страницы

- Главная страница: hero-блок, преимущества, популярные товары и якорные ссылки.
- Каталог: сетка карточек товаров, категории и статический фильтр.
- Карточка товара: изображение, описание, цена, кнопка заявки и таблица характеристик.
- Заявка: форма с именем, e-mail, телефоном, выбранным товаром, комментарием и согласием.
- Контакты: контактная информация и переход к форме заявки.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- Flexbox для шапки, навигации и групп кнопок;
- CSS Grid для hero-блока, каталога, карточек и формы;
- базовое позиционирование: `sticky`, `relative`, `absolute`, `fixed`, `z-index`;
- структурированный файл `css/style.css`.

## Инструкция по просмотру

1. Открыть опубликованную версию через GitHub Pages.
2. Или открыть файл `index.html` в браузере локально.
3. Проверить переходы по меню: главная, каталог, товар, заявка, контакты.
4. Проверить форму заявки и модальное окно на главной странице.
